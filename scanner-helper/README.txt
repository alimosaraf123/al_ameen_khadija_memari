Al-Ameen Mission Academy, Memari - Universal Windows Scanner Helper
=======================================================================

Use this folder on ANY Windows PC that has a USB/Network scanner attached
(Epson, Canon, HP, Brother, etc.). Different PCs can use different scanners!

Quick Setup on Each Operator PC:
1. Make sure the scanner's Windows driver is installed (so Windows sees it).
2. Double-click "Install-AutoStart.bat" once (so it runs silently every time
   the PC starts), OR double-click "Start-Scanner-Helper.bat" whenever needed.
3. Open Al-Ameen Software -> Students -> + Student Entry ->
   click "Direct Scan (Scanner)"!

Notes:
- Runs locally on http://127.0.0.1:4789 using built-in Windows WIA.
- If a very old scanner only has a TWAIN driver (no WIA), install free NAPS2
  (https://www.naps2.com/) on that PC and it will automatically use NAPS2.
