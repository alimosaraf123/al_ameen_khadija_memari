====================================================================
  Al-Ameen Mission Academy Memari - Calling Booth Server Installer
====================================================================

এই ফোল্ডারটি Pen Drive-এ কপি করে হোস্টেলের ডেডিকেটেড PC / Mini PC-তে
নিয়ে যান এবং নিচের ৩টি সহজ ধাপ অনুসরণ করুন:

ধাপ ১:
- হোস্টেলের ওই PC-তে Pen Drive লাগান এবং পুরো "Calling_Booth_Installer"
  ফোল্ডারটি ওপেন করুন।

ধাপ ২:
- "INSTALL_AND_START.bat" ফাইলটির ওপর ডাবল-ক্লিক করুন
  (Windows অনুমতি চাইলে "Yes" দিন)।
- এটি নিজে থেকেই:
  1. Node.js না থাকলে ইনস্টল করবে,
  2. সার্ভারের ফাইলগুলো C:\AlAmeen_Calling_Server-এ কপি করবে,
  3. Windows Firewall-এ Port 5060 ও 3000 খুলে দেবে,
  4. Windows Auto-Start চালু করে দেবে (যাতে পিসি অন করামাত্রই
     কোনো কমান্ড ছাড়াই কলিং সিস্টেম নিজে থেকেই চালু হয়ে যায়),
  5. এবং সাথে সাথেই কলিং সিস্টেম ACTIVE করে দেবে!

- ইনস্টল সফল হলে Pen Drive খুলে নিতে পারেন।

ধাপ ৩ (খুব জরুরি - Static IP):
- ওই হোস্টেল PC-কে LAN কেবল দিয়ে রাউটারে লাগাবেন এবং PC-টির IPv4 Address
  "192.168.0.133" সেট করে রাখবেন (তাহলে Yealink ফোনে কোনো সেটিংস
  পাল্টাতে হবে না)।

সহায়ক টুলস:
- সার্ভার চলছে কি না দেখতে: "CHECK_STATUS.bat" চালান।
- সার্ভার রিস্টার্ট করতে: "RESTART_SERVER.bat" চালান।
- বন্ধ/রিমুভ করতে: "UNINSTALL_SERVER.bat" চালান।
