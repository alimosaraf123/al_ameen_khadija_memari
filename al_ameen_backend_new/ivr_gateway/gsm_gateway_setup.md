# GSM Gateway (সিম কার্ড মডিউল) সেটআপ গাইড

হোস্টেলে স্টুডেন্টদের আউটগোয়িং কল মোবাইলে পাঠাতে একটি GSM Gateway ডিভাইস (যেমন: **Dinstar UC2000-VE/VF**, **GoIP-4/8**, অথবা **Yeastar TG400**) ব্যবহৃত হয়।

---

## ১. ডিভাইসের সংযোগ
1. GSM Gateway-এর পেছনের স্লটে স্কুলের অফিসিয়াল সিম কার্ডগুলো (Jio / Airtel / Vi) প্রবেশ করান।
2. ডিভাইসে ল্যান কেবল লাগিয়ে লোকাল সুইচে যুক্ত করুন।
3. ব্রাউজারে গেটওয়ের আইপি খুলুন (ডিফল্ট: `192.168.1.200` বা রাউটারে পাওয়া আইপি)।

---

## ২. SIP ট্রাঙ্ক কনফিগারেশন (Asterisk বা লোকাল সার্ভারের সাথে)
1. **SIP Config** -> **SIP Trunk**-এ যান।
2. **Trunk Type:** Peer-to-Peer
3. **Server IP / Domain:** `<সার্ভারের_আইপি>` (যেমন: `192.168.1.100`)
4. **Port:** 5060
5. **Transport:** UDP

---

## ৩. রাউটিং নিয়ম (Routing Rules: IP -> Tel)
1. **Routing** -> **IP to Tel Routing**-এ যান।
2. **Source:** `SIP Trunk`
3. **Destination:** `GSM SIM Group` (বা নির্দিষ্ট সিম স্লট: SIM 1, SIM 2...)।
4. **Call Mode:** Round-Robin (একটি সিমে কথা চললে স্বয়ংক্রিয়ভাবে পরবর্তী সিমে কল যাবে)।

---

## ৪. অল্টারনেটিভ: অ্যান্ড্রয়েড ফোনকে GSM গেটওয়ে হিসেবে ব্যবহার (Android Gateway)
যদি হার্ডওয়্যার গেটওয়ে না থাকে, তবে একটি অ্যান্ড্রয়েড ফোনে লোকাল ব্রিজ বা ADB কানেক্টিভিটি ব্যবহার করে কল ট্রানজিট করা যায়, যা আমরা ইতিমধ্যে আপনার ভিভো ফোনে সফলভাবে টেস্ট করেছি।
